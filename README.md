# Bank Management System

A simple Bank Management System developed using Python and modular programming.

## Features
- Create Bank Account
- Display All Accounts
- Search Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Update Account Details
- Delete Bank Account

## Technologies Used
- Python
- Dictionary
- Functions
- Modules
- Exception Handling

## Project Structure
Each operation is implemented in a separate Python module for better code organization and maintainability.

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python main.py
```
